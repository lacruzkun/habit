# FocusFlow — Data Schema

Room database: `focusflow.db`, schema version **1**. Schema JSON is exported to
`app/schemas/` by KSP. Preferences live separately in DataStore.

## Tables

### `categories`

| Column | Type | Notes |
| --- | --- | --- |
| id | INTEGER PK | autogenerated |
| name | TEXT | display name |
| colorArgb | INTEGER | packed ARGB color |
| iconKey | TEXT | stable key resolved by `IconCatalog` |
| createdAt | INTEGER | epoch millis |

### `tasks`

| Column | Type | Notes |
| --- | --- | --- |
| id | INTEGER PK | autogenerated |
| name, description | TEXT | task text |
| categoryId | INTEGER? | FK → categories, `SET_NULL` |
| iconKey, colorArgb | TEXT / INTEGER | presentation |
| dailyTargetMinutes, weeklyTargetMinutes | INTEGER | focus goals |
| yearlyTargetMinutes | INTEGER? | optional |
| priority | TEXT | enum `LOW`/`MEDIUM`/`HIGH`/`URGENT` |
| createdAt, archivedAt | INTEGER | archive is soft delete |
| active | INTEGER | included in the daily plan |
| scheduledDaysMask | INTEGER | bit 0 = Monday … bit 6 = Sunday |
| reminderEnabled, reminderMinutes | INTEGER | local reminder |
| focusMinutes, shortBreakMinutes, longBreakMinutes | INTEGER | per-task Pomodoro |
| sessionsBeforeLongBreak | INTEGER | cycle length |
| sortOrder | INTEGER | manual ordering |

### `focus_sessions`

A completed or abandoned timer run.

| Column | Type | Notes |
| --- | --- | --- |
| id | INTEGER PK | autogenerated |
| taskId | INTEGER? | FK → tasks, `SET_NULL` |
| taskNameSnapshot | TEXT | survives task deletion |
| sessionType | TEXT | `FOCUS` / `SHORT_BREAK` / `LONG_BREAK` |
| status | TEXT | `COMPLETED` / `INTERRUPTED` / `ABANDONED` |
| startedAt, endedAt | INTEGER | epoch millis |
| plannedSeconds, focusSeconds | INTEGER | planned vs. actual focus |
| note | TEXT? | optional |
| createdAt | INTEGER | epoch millis |

### `focus_segments`

Runs of actual focus time, used to exclude pauses and to split totals across days.

| Column | Type | Notes |
| --- | --- | --- |
| id | INTEGER PK | autogenerated |
| sessionId | INTEGER | FK → focus_sessions, `CASCADE` |
| startedAt, endedAt | INTEGER | epoch millis |

### `habits`

| Column | Type | Notes |
| --- | --- | --- |
| id | INTEGER PK | autogenerated |
| name, description | TEXT | habit text |
| iconKey, colorArgb | TEXT / INTEGER | presentation |
| frequency | TEXT | `DAILY` / `WEEKLY_DAYS` / `WEEKLY_COUNT` |
| daysMask | INTEGER | used by `WEEKLY_DAYS` |
| weeklyTargetCount | INTEGER | used by `WEEKLY_COUNT` |
| targetValue, unit | REAL / TEXT | e.g. 8 glasses |
| startEpochDay | INTEGER | LocalDate epoch day |
| reminderEnabled, reminderMinutes | INTEGER | local reminder |
| createdAt, archivedAt | INTEGER | archive is soft delete |

### `habit_completions`

| Column | Type | Notes |
| --- | --- | --- |
| id | INTEGER PK | autogenerated |
| habitId | INTEGER | FK → habits, `CASCADE` |
| epochDay | INTEGER | unique with habitId |
| value, targetValue | REAL | snapshots at check-in time |
| completedAt | INTEGER | epoch millis |

### `distractions`

| Column | Type | Notes |
| --- | --- | --- |
| id | INTEGER PK | autogenerated |
| activity | TEXT | what pulled the user away |
| startedAt, endedAt | INTEGER | epoch millis |
| note | TEXT? | optional |
| createdAt | INTEGER | epoch millis |

### `reflections`

One weekly review per week.

| Column | Type | Notes |
| --- | --- | --- |
| id | INTEGER PK | autogenerated |
| weekStartEpochDay | INTEGER | unique |
| wentWell, needsImprovement, nextFocus | TEXT | reflection prompts |
| updatedAt | INTEGER | epoch millis |

### `reminders`

| Column | Type | Notes |
| --- | --- | --- |
| id | INTEGER PK | autogenerated |
| title, message | TEXT | notification content |
| type | TEXT | currently `CUSTOM` for this table |
| timeMinutes | INTEGER | minutes after midnight |
| daysMask | INTEGER | bit 0 = Monday … bit 6 = Sunday |
| enabled | INTEGER | scheduled or not |
| createdAt | INTEGER | epoch millis |

### `active_timer`

Single row (`id = 1`) snapshot of the running timer so process death does not lose a
session. Mirrors the `TimerState` fields: task, session type, status, planned seconds,
accumulated milliseconds, elapsed/wall anchors, cycle count, and serialized segments.

## Preferences (DataStore)

`userName`, `avatarStyle`, `themeMode`, `startOfWeek`, `dailyFocusTargetMinutes`,
`defaultFocusMinutes`, `defaultShortBreakMinutes`, `defaultLongBreakMinutes`,
`defaultSessionsBeforeLongBreak`, `notificationsEnabled`, `onboardingComplete`,
`focusCycleCount`.

## JSON backup (schema version 1)

```json
{
  "schemaVersion": 1,
  "exportedAt": 1700000000000,
  "categories": [],
  "tasks": [],
  "sessions": [],
  "segments": [],
  "habits": [],
  "completions": [],
  "distractions": [],
  "reflections": [],
  "reminders": [],
  "preferences": {}
}
```

Import validates the schema version and a maximum of 500,000 records, then deletes and
reinserts all tables inside a single transaction. Preferences are replaced after the
transaction. CSV export is session-level only and intended for spreadsheets, not restore.

## Relationships

```
categories 1 ── n tasks
tasks      1 ── n focus_sessions (SET_NULL keeps history)
focus_sessions 1 ── n focus_segments (CASCADE)
habits     1 ── n habit_completions (CASCADE)
```

Tasks and habits use `archivedAt` for soft deletion. Permanent deletion removes the row;
task-linked sessions keep their `taskNameSnapshot`.
